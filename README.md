# 微信年轮

> 把一年里容易被忽略的微信小事，变成一份只属于自己的年度档案。

当前候选 **V0.5.2 · Apple 芯片 Mac**

微信年轮是本地微信年度报告工具。可导入 Mac 微信合并转发的聊天 ZIP/TXT、已有聊天 JSON/CSV、微信支付个人对账 CSV、朋友圈结构化记录或标准备份。在首页点击「导入记录」或拖入文件。微信转发片段需确认昵称和会话。报告在本机生成，可按年查看图表，保存分享图或私人备份。

本项目不是腾讯或微信官方产品。“微信”是其权利人的商标。

## 它能统计什么

- 发出/收到多少条消息、活跃多少天、最长连续活跃多少天
- 12 个月和 24 小时分布，文字、图片、语音、视频、表情、文件等类型
- 发消息最多的会话（仅在本机显示，分享图默认隐藏姓名）
- 仍保留系统痕迹的本人撤回，以及数据中明确存在的删除标记
- 识别到的朋友圈发表、评论和点赞
- 微信支付账单里的红包/转账收支笔数与金额
- 各来源的记录日期、条数及覆盖状态
- 每个导入文件识别了多少条、跳过多少条以及具体警告

它不会声称能找回彻底删除且毫无残留的记录，也不会把未导入数据时的 `0` 冒充真实结论。

## 在 Mac 上取得聊天文件

1. 在较新的 Mac 微信里，在一个会话中多选消息，再选「合并转发」→「其他应用」。
2. 用本地分享接收器取得原始 ZIP，例如渡口的「暂存到渡口」入口。取得文件后可直接拖入微信年轮，也可选解压后的 `聊天记录.txt`。[渡口手动接收指南](https://github.com/qzz0518/Dukou#第一次使用)
3. 为每份文件确认你的发送人昵称和会话名称。同一个会话分批导入时填写同一个名称。

合并转发只覆盖你选中的消息。首轮格式验证使用公开合成转发包，真实微信账号导出的链路另行验收。已有 JSON/CSV 可以直接导入。微信内迁移备份用于恢复；微信支付邮件里的 ZIP 需要先解压成 CSV。

## 本地运行

需要 Node.js 22。进入项目文件夹后运行：

```bash
npm ci
npm run dev:desktop
```

检查代码：

```bash
npm run check
```

构建 Apple 芯片 Mac 候选：

```bash
npm run dist:mac
npm run verify:packaged -- release/mac-arm64
```

GitHub Actions 的「Build Mac candidate」手动构建 arm64 DMG、ZIP、SHA-256 校验和与构建来源证明。产物上传到 Actions。正式下载版以 Apple Developer ID 签名、公证和安装实测为门槛。[候选说明](docs/releases/v0.5.2.md)

## 导入格式

1. 微信支付：官方“用于个人对账”的 CSV；只有账单声明范围覆盖完整年份时才标为完整。
2. 聊天：Mac 微信原始转发 ZIP/TXT、常见 JSON/CSV，以及多种 EchoTrace/WeFlow 风格字段和嵌套会话结构。
3. 朋友圈：包含 `time`、`type`、`isOwn` 等字段的 JSON/CSV；没有本人归属字段的记录不会擅自计入。
4. 微信年轮标准 JSON：可在“数据与隐私”页按当前年份或全部年份导出后再次导入。
5. 可同时多选以上文件，桌面端也可选择整个文件夹；图片、视频和微信原始数据库不会被当作结构化导入文件。

完整字段见 [数据格式](docs/DATA-FORMAT.md)。可先导入 `examples/wechat-yearbook-example.json` 验证流程。

## 隐私与安全

- 不要求微信账号、密码或支付密码。
- 原文件保存在用户选择的位置。退出应用后，当前报告会清空。
- 解析在隔离的本地后台线程完成；Electron 拒绝任意本地导航、网页嵌入和未使用的系统权限。
- 不分析他人账号，不提供监控、窃取或绕过系统保护的能力。
- 分享图不含聊天原文、联系人、群名和具体金额。
- 标准 JSON 会包含原始内容与联系人，只适合本人备份，不应公开上传。

详见 [隐私说明](PRIVACY.md) 与 [安全边界](docs/SECURITY-BOUNDARY.md)。
