隐私说明

微信年轮在你的设备上读取和计算你导入的文件：不登录、不上传、不联网分析。生效版本 V0.5.2。

1本地处理

  • 文件由你通过系统选择器、拖放或 Finder 的「打开方式」主动选择；应用不把原文件复制到自己的数据目录。
  • 文件解析在本地后台线程完成，统计、图表与分享图只在本机生成。
  • 退出应用后当前报告会清空；分享图与备份留在你自己选择的位置。
  • 当前版本没有遥测、广告 SDK、第三方统计或云端 AI 接口；核心报告不需要联网。

2两类导出，请分清用途

  • 脱敏分享图（PNG）：只包含汇总数量，默认隐藏昵称、群名、聊天原文与具体金额，适合公开分享；公开发布前请自行检查图片。
  • 含原文的 JSON 备份：包含聊天内容与联系人，只适合自己备份，请勿提交到 GitHub、上传公开网盘或发送给陌生人。

3安全边界

  • 不扫描微信进程、不读取微信本地数据库、不提取任何密钥；不要求微信账号、密码或支付密码。
  • 桌面壳拒绝相机、麦克风、蓝牙等未使用的系统权限与未知网址；只有你主动点击白名单内的 GitHub 链接时，才交给系统默认浏览器打开。
  • 不分析他人账号，不提供监控、窃取或绕过系统保护的能力。

4请妥善保管敏感文件

聊天导出与微信年轮标准 JSON 可能包含联系人、群名、消息内容、时间与删除标记；支付账单可能包含交易对方与金额。

这些文件是你的私人数据。请保存在自己的设备里，不要提交到代码仓库、公开网盘或发送给陌生人。

5开源与审计

  • MIT 开源：代码公开在 GitHub 仓库，可以自行阅读、构建与检查。
  • 依赖审计：发布时 npm audit 为 0 个已知漏洞，依赖版本锁定。
  • SHA-256 校验：下载页提供 DMG 的 SHA-256，可在本机用 shasum -a 256 文件名 核对；构建产物附带构建来源证明。
