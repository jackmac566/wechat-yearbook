把选中的微信聊天，
做成自己的年度回顾。

导入你在微信里合并转发的聊天、支付账单或朋友圈记录，在本机生成只属于你的年报。不上传、不登录、不联网分析——数据留在你的设备里。

下载 macOS 版（Apple 芯片 · DMG） 先看使用指南

先说清楚：这是「选中聊天」的回顾——覆盖范围取决于你导入的文件，不是全账号年报。

一份年报，能看到什么

每个数字都来自你导入的记录：缺失与实际零值分开标注，没有证据的内容不会被编造。

聊天回顾

  • 发出与收到的条数、活跃天数、最长连续活跃
  • 最活跃的一天、最常出现的时段
  • 文字、图片、语音、视频、表情、文件等表达方式分布
  • 双向会话排行：和你互动最多的对话
  • 仍保留系统痕迹的撤回、数据中明确存在的删除标记

红包与转账

  • 发出红包、收到红包、发出转账、收到转账四类汇总
  • 按月的收支走势
  • 按日期查询发出的红包明细
  • 金额一律以支付账单为准——聊天里的红包卡片只是标记，不统计金额

本地与隐私

  • 文件在本机解析与计算，不上传、不登录、不联网分析
  • 年报故事封面写明观察区间与来源
  • 分享图为 PNG，默认隐藏昵称、群名、聊天原文与金额

朋友圈：仅统计有明确本人归属的记录，覆盖可能不完整（实验功能）。支持导入：聊天合并转发 ZIP / TXT、微信支付账单 CSV、朋友圈 JSON / CSV、微信年轮标准 JSON。

三步，得到你的年报

从 Mac 微信的「合并转发」开始，账单与朋友圈文件也能一起导入。

1

合并转发，保存聊天文件

在 Mac 微信里多选一个会话的消息，选「合并转发」，把导出的 ZIP（或 TXT）保存到电脑。

2

拖进微信年轮，确认昵称

把文件拖进应用（或点「导入记录」选择文件），确认你的发送人昵称并填写会话名称。账单 CSV、朋友圈文件也能一起导入。

3

查看年报，导出分享图

打开年报故事与详细图表，封面写明观察区间与来源。可保存脱敏的分享图，或仅给自己的含原文 JSON 备份。

查看完整使用指南 →，含账单与朋友圈文件的获取步骤。

诚实说明：它统计什么，不统计什么

微信年轮不把未导入的数据当成零，也不会声称找回无法恢复的记录。

只统计你导入的片段 这是「选中聊天」的回顾，不是全账号年报；覆盖范围取决于你导入的文件。
朋友圈覆盖有限 仅统计有明确本人归属的记录，覆盖可能不完整。
聊天红包卡片不统计金额 红包与转账的金额、笔数以微信支付账单为准，聊天里的红包只是标记。
旧备份缺少方向字段时无法逆推 无法判断发出 / 收到的记录不会被擅自计入统计。
彻底删除且无残留的记录无法恢复 应用不会从云端补齐、估算或伪造缺失数据。
升级后需要重新导入文件 应用退出后报告会清空；保存过的分享图与备份不受影响。
