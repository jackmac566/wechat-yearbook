使用指南

从取得数据到查看年报。聊天、支付账单、朋友圈三种文件都可以独立开始，也可以一次多选导入。

1取得聊天数据（Mac 微信合并转发）

微信年轮回顾的是「你选中的聊天」，覆盖范围取决于你的选区。

  1. 打开 Mac 微信，进入一个会话，多选你想回顾的消息，点击「合并转发」。
  2. 选择「其他应用」接收原始文件：有微信流时选「发送到自定义」保存 ZIP；或使用渡口的「暂存到渡口」入口取得文件（渡口手动接收指南）。
  3. 也可以先解压 ZIP，保存其中的 聊天记录.txt，再导入 TXT。
  4. 把 ZIP 或 TXT 拖进微信年轮（或点「导入记录」选择文件）。为这份文件确认你的发送人昵称，并填写会话名称。
同一会话分批导入时，请填写同一个会话名称，报告才能正确合并。已有微信年轮标准 JSON、常见聊天 JSON / CSV 也可以直接导入。

2取得支付账单（微信支付个人对账 CSV）

红包与转账的笔数、金额与方向，一律以微信支付账单为准。

  1. 手机微信：我 → 服务 → 钱包 → 账单，在常见问题里选择「下载账单」。
  2. 账单用途选「用于个人对账」，选择你要回顾的年份，填写接收邮箱。
  3. 微信支付会把加密 ZIP 发送到你的邮箱，下载后解压得到 CSV，拖进微信年轮导入。
聊天里的红包卡片通常不显示金额，因此只作为标记；最终金额与笔数以账单为准，退款与无效交易不计入。官方下载账单入口见财付通官方说明。

3朋友圈记录（实验功能）

朋友圈统计是实验功能，覆盖有限。

  1. 需要包含时间与本人归属字段（如 isOwn）的 JSON / CSV 文件。
  2. 导入后，仅统计有明确本人归属的记录；无法确认归属的记录不会被计入，并会单独提示未计入数量。
微信年轮不会仅凭电脑缓存声称朋友圈覆盖完整。没有本人归属字段的文件，导入后朋友圈板块会显示为未计入。

4常见问题

为什么不是全账号年报？

因为微信年轮统计的是你导入的片段：合并转发只覆盖你选中的消息，账单只覆盖你申请下载的账期。应用不会从云端补齐或猜测没有导入的数据，覆盖范围取决于导入的文件。

覆盖范围怎么看？

在「数据与隐私」页，每个来源都会显示观察区间、记录条数与覆盖状态，缺失与实际零值分开标注；年报故事封面也会写明聊天、账单与朋友圈各自的观察区间与来源。

我的数据会去哪里？

留在你的设备里。文件在原位置读取，解析在本机完成，不上传、不登录、不联网分析。退出应用后当前报告会清空；分享图与备份保存在你自己选择的位置。

能否找回已经删除的记录？

不能。彻底删除且没有残留的记录无法恢复，应用不会估算或伪造。仍保留系统痕迹的撤回、以及数据中明确存在的删除标记，才会被统计。

升级后需要重新导入吗？

需要。应用退出后报告会清空，升级到新版本后请重新导入文件；你保存过的分享图和私人备份不受影响，仍可随时重新导入查看。

红包金额为什么以账单为准？

聊天里的红包卡片通常不显示最终金额，只能作为「这里发过红包」的标记；金额与笔数一律以导入的微信支付账单为准。
