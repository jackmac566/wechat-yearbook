# 微信年轮 V0.4.0 · Mac 候选

本轮交付面向 Apple 芯片 Mac，补齐八个板块的可视化与覆盖说明。候选版延续 V0.3.0 的本地导入链路（微信合并转发 ZIP/TXT、聊天 JSON/CSV、支付账单、朋友圈与标准备份），并把分析层早已计算的序列全部画到界面上。

- 年报故事：封面写明聊天、账单与朋友圈的观察区间、记录数与覆盖状态，只展开有证据的章节，隐私结尾页常驻。
- 详细总览：月度趋势同时展示发出与收到，按来源显示观察区间与记录数，区分「账期已覆盖」与「聊天仅有片段」。
- 聊天轨迹：全年日历热力图与最活跃的一天，工作日 / 周末 / 深夜（00:00–05:59）对比，时段图在发出与收到间切换；方向未知的消息不计入收到并单独说明。
- 关系温度：会话排行改为发出与收到的双向互动，附最近活跃日期与 12 个月迷你趋势。
- 朋友圈：发表、评论、点赞按月分布；明确提示无法确认本人归属、未计入统计的记录数。
- 红包与转账：四类月度收支走势与金额 / 笔数切换，账期覆盖逐月标注，退款与无效交易口径独立说明。
- 数据与隐私：逐来源展示观察区间与记录数；「脱敏分享图」与「含原文的 JSON 备份」分成两个明确的导出区。
- 更新日志：新增 Mac 兼容范围、已知限制、标准 JSON 格式变化与升级后是否需要重新导入的说明。
- 准确：修复无效 UTF-8 聊天记录被误报为「ZIP 已损坏」的问题。

## 分发验收

候选构建提供 DMG、ZIP 与 SHA-256 校验和，使用临时签名（ad hoc），定位为验收包。真实微信账号的手动转发链路仍需用专门编写的测试消息独立验收。

公开发行应使用 Developer ID Application 证书和 Hardened Runtime 完成签名，提交 Apple 公证并装订票据。在干净的目标系统从浏览器下载最终安装包，用 Finder 完成安装、首次启动和离线导入验证，再发布同一份已核验的包与校验和。[Apple Developer ID 分发说明](https://developer.apple.com/developer-id/)
