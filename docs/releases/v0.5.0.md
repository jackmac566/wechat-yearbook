# 微信年轮 V0.5.0 · Mac 候选

本轮交付面向 Apple 芯片 Mac，新增内置的微信分享入口。候选版延续 V0.4.0 的八个板块可视化与本地导入链路，并解决"如何把微信聊天交给微信年轮"的核心体验问题。

## 内置分享入口

- 在微信中多选消息 → 合并转发 → 其他应用 → **导入到微信年轮**：转发包直接进入应用的导入与发送人确认流程。
- 不再需要另装接收工具（如微信流）、手动保存 ZIP、再拖进应用，三个步骤合成一步。
- 共享扩展把微信传来的合并转发包（ZIP 附件）写入应用收件箱，主应用监听收件箱并自动开始导入；已处理的文件移入 `processed` 子目录，重启应用不会重复导入。
- 扩展实现为 1×1 透明视图的共享扩展，复制完成后立即结束分享面板，不弹确认窗口；转发包仍只在用户本机读取。

## 已知边界

- 共享扩展与主应用之间使用固定收件箱路径 `~/Library/Application Support/wechat-yearbook/inbox`，不依赖 App Group（App Group 需要付费开发者计划）。
- 当前安装包为临时签名（ad hoc）。用户从官网下载后首次打开需在「系统设置 → 隐私与安全性」确认，或右键打开。
- 正式发行需要 Developer ID 签名与 Apple 公证；用户已决定暂不加入 Apple Developer Program（99 美元/年），该步骤延后。

## 分发验收

候选构建提供 DMG、ZIP 与 SHA-256 校验和，使用临时签名（ad hoc），定位为验收包。共享扩展注册与收件箱自动导入已用合成数据实测；真实微信分享面板中的显示名与交互需在真实微信中复核。
