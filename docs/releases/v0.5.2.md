# 微信年轮 V0.5.2 Mac 候选

基于 V0.5.1。用户在 Mac 微信取得真实聊天 ZIP，并确认能对应到自己的昵称。用户提供的转发文本截图显示红包标记及祝福语，未显示金额。本轮未读取用户实际 ZIP 或账单。

- 只导入聊天时，红包与转账页可以显示已识别的红包标记，按本人和他人发出的消息区分。
- 支付金额和交易次数来自导入的微信支付账单。可按日期查看发出的红包明细。聊天标记不与账单交易自动匹配。
- 聊天转发文件的原有签名保持不变，旧备份仍可与同一聊天片段去重。不同选区中的重叠片段仍按原有规则处理。
- 下载账单入口见[财付通官方说明](https://posts.tenpay.com/posts/4d1501526a8baf82000881c008b63f1d.html)。Mac 候选的发布边界见 [V0.5.1 验收记录](v0.5.1.md)。

60 项自动测试及 Mac 包检查通过。使用合成聊天 ZIP 和账单 CSV，在从 DMG 复制的应用上离线验证了标记计数、账单导入、退款行排除与按日期查明细。真实微信支付账单兼容性待进一步验收。
