# 微信年轮 V0.5.1 Mac 候选

基于 V0.5.0 工作树。面向 Apple 芯片 Mac，以本地文件生成个人微信回顾。产品形态是官网提供 DMG，下载后在桌面应用内导入、看报告和分享，导入与分析在本机完成。

## 使用路径

1. 首页点「导入记录」，或将文件拖进窗口。聊天、支付账单、朋友圈均可独立开始。
2. 导入微信转发 ZIP 或 TXT 时，选本人昵称并填写会话名称。已有标准备份、账单及结构化记录可以直接解析。
3. 应用打开所选年份的故事。通过「详细数据」查看总览、聊天轨迹、关系温度、朋友圈、红包与转账。用「导入记录」补充其他文件。
4. 「分享图」生成隐藏姓名、正文和金额的 PNG。「数据与隐私」可以保存含原文的私人备份，下次重新导入继续看。

默认界面保留操作提示、记录范围和隐私提醒。获取指引按需打开，版本与技术验收写在交接和发布文档中。

## 数据与发布边界

- 转发文件覆盖已选消息。完整账号年报需要另行验证数据获取方式。现阶段需已有兼容文件或合适的本机接收工具，微信内直接分享入口尚待实机验证。可参考[渡口手动接收指南](https://github.com/qzz0518/Dukou#第一次使用)。
- 账单用个人对账 CSV。红包与转账的笔数、金额和方向以账单为准。朋友圈本人统计需要文件有明确归属。
- 已选择的聊天等原文件保持原位。报表退出后清空，保存的备份和分享图由用户管理。
- 常规包仅做 Mac 文件导入。实验分享扩展源码留在开发目录。正式官网分发仍需 Developer ID 签名、公证与干净 Mac 下载安装验收。见 [Apple 官网分发说明](https://developer.apple.com/developer-id/)。
