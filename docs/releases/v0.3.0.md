# 微信年轮 V0.3.0 · Mac 候选

本轮交付面向 Apple 芯片 Mac。候选版支持在本机导入微信原始合并转发 ZIP/TXT、已有聊天 JSON/CSV、支付账单、朋友圈及标准备份，生成年度报告和隐私分享图。

- 批量导入可查看文件进度、取消整批操作并回看逐文件失败原因。
- 转发文件逐份确认发送人和会话名称。报告与分享卡显示片段覆盖。
- 报告区分缺失数据和有效零值，按年备份只包含所选年份。
- 演示分享图带演示标记，示例记录与真实导入分开处理。
- 生产包的启动和资源加载纳入 Mac 验收。候选构建提供 DMG、ZIP、SHA-256 校验和与 GitHub 构建来源证明。

## 分发验收

在 GitHub Actions 手动运行「Build Mac candidate」可取得候选构建附件。候选使用临时签名（ad hoc），定位为验收包。

公开发行应使用 Developer ID Application 证书和 Hardened Runtime 完成签名，提交 Apple 公证并装订票据。在干净的目标系统从浏览器下载最终安装包，用 Finder 完成安装、首次启动和离线导入验证，再发布同一份已核验的包与校验和。候选工作流只上传构建附件，公开发行单独进行。[Apple Developer ID 分发说明](https://developer.apple.com/developer-id/)
